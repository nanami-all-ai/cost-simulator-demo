# 品ごとの原価・粗利と値上げ試算（1画面デモ）

Claude Codeで作成（七海）。

## できること
- 品ごとに販売価格と原価（材料ごとの「使用量×単価」、または原価の直接入力）を入れると、粗利と粗利率を出す。
- 材料費の上昇率（スライダーまたは数値）を入れると、上昇後の原価・粗利・粗利率、粗利の減り額を出し、減りが大きい順に並べる。
- 元の粗利率に戻すための販売価格を、10円単位に切り上げた目安として出す（式：新原価×価格÷原価）。
- 材料ごとに「値上がり対象」のチェックがあり、袋・容器など上がらないものは外せる（一部の材料だけ上がる場合の計算）。
- 一覧をCSVで書き出せる（BOM付きUTF-8。先頭が `=` `+` `-` `@` のセルには `'` を付ける）。

## 使い方
1. `index.html` をブラウザで開く（サンプルは架空。「サンプルを消す」で空になる）。
2. 品名・販売価格・材料ごとの使用量と単価（または原価）を入れる。
3. 上昇率を動かすと一覧が変わる。必要なら「CSVで書き出す」。

## 限界
- 税、人件費・手間賃、光熱費、家賃、ロス（作りすぎ・廃棄・試作）は含まない。材料費と包装などの直接費だけの粗利。
- 直接入力した原価は全額が上がる前提で計算する。
- 提案価格は計算上の目安。値上げ後の売れ行き（需要の変化）は考慮しない。
- 粗利が0以下の品、販売価格が0の品は提案価格を出さない（備考を表示）。
- 入力は画面内で処理するだけで、保存も外部送信もしない（再読み込みで消える）。依存なしの単一HTML。
